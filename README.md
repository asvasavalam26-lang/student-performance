# Student CGPA Performance Management System

## Purpose

This project calculates student CGPA and categorizes student performance.

## Technology

- Python
- Pytest
- Black
- Ruff

## Project Structure

src/       - Application source code
tests/     - Automated tests
docs/      - Documentation
config/    - Configuration files

## Coding Rules

- Follow PEP 8
- Use meaningful function names
- Write unit tests
- Validate user input
- Do not store passwords or secrets in source code
